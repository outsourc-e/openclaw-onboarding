2
Pick your model stack before you install
5 min

This is where most people lose the plot. They install the gateway first, then wander around deciding providers. I do the opposite. Pick the cost model up front, then wire OpenClaw around it.

Free

OpenRouter free models

$0
  • Best for trying the stack without spending money.
  • Grab one API key from openrouter.ai.
  • Use rotating free models for chat and low-stakes tasks.
  • Tradeoff: rate limits and quality can swing.
Recommended

$20/mo coding plan

~$20/mo flat
  • Best value if you're serious and shipping every day.
  • Use a ChatGPT subscription with Codex access, or run MiniMax for a cheap generalist lane.
  • Add Claude later for higher-stakes reasoning with a standard API key if you need it.
  • Tradeoff: you need at least one paid subscription.
Private

Local Ollama

$0 after hardware
  • Best for privacy, offline work, and no API usage anxiety.
  • Install Ollama and pull qwen3:8b or qwen3.5:9b.
  • Great on a dedicated box or secondary machine.
  • Tradeoff: you need hardware, and the reasoning ceiling is lower.

Part 3 · Steal My Setup
10
Use heartbeats for background checks without becoming annoying
10 min

This is one of the big unlocks. I don't want a cron explosion for every little thing. I want a heartbeat loop that batches cheap checks, rotates through them, and only interrupts me when there's actually signal.

~/.openclaw/workspace/HEARTBEAT.md
## Active Checks - Rotate: email, calendar, weather, mentions - Quiet hours: 23:00-08:00 - If nothing needs attention, stay quiet - If something matters, alert once with the useful detail ## Background Work - Review recent memory files - Update MEMORY.md if the pattern is durable - Check project repos for obvious drift
HB_SIGNAL.md
# HB_SIGNAL.md - Morning pass: weather + calendar - Midday pass: mentions + urgent inbox - Late afternoon pass: project drift, open PRs, notifications - Evening pass: upcoming meetings, inbox, memory cleanup Rule: be proactive without being annoying. If there is no real delta, do not send a message.
11
Route by importance and cut costs by 70%+
12 min

The expensive mistake is using the same premium model for everything. I route by task shape. Cheap checks go to cheap models. High-stakes thinking gets the premium lane. That's how I got real output without lighting money on fire.

LaneModelWhy it belongs there
HeartbeatsGemini FlashNearly free, fast, good enough for lightweight checks
Main chatClaude SonnetReliable balance of speed, quality, and tone
CodingGPT-5.4 Codex or MiniMaxBest value for implementation throughput
Heavy reasoningClaude OpusOracle pattern for money, architecture, and public output
Sub-agentsDelegated laneLong tasks run in the background while the parent stays responsive

Steal My Setup, the six rules that actually matter
What I'd keep if you deleted everything else
1. Keep MEMORY.md under 80 lines.Raw notes belong in memory/YYYY-MM-DD.md. MEMORY is curated wisdom. The daily file is the journal.
2. Write, don't mental-note.Agents restart. Context compacts. If a lesson matters, write it to disk or it's gone.
3. Use the oracle pattern.When the stakes are money, public posts, or architecture, spawn Claude Opus as a critique pass before you ship.
4. HB_SIGNAL beats cron for batched checks.Use cron when exact timing matters. Use heartbeat loops when you want rotating checks that can drift a little and stay cheap.
5. Sub-agents are for long work.The parent should stay responsive. The child should do the 30-minute task and report back when it's done.
6. Cost routing is a feature.Flash for checks, Sonnet for chat, Opus for oracles, Codex for code. Don't pay premium rates for low-value work.
Key Principle
Customizing isn't the skill. Output is. The agent handles the background work. You get 20-30% more done. More reps turns into better signal, and better signal turns into better outcomes.
